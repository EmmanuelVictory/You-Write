# 📖 Blog Platform ✍️

A modern blogging platform that allows users to write, publish and manage blog posts while also browsing content from other users. Built as a beginner friendly full stack style project with clear CRUD functionality, authentication flow and a realistic data structure that is easy to understand and extend.



## 🚀 Features

- 🔐 User authentication (register and login)  
- ✍️ Create, edit and delete personal blog posts  
- 🌍 Public feed displaying all published posts  
- 📄 View individual blog posts in detail  
- 📚 Track “read history” of opened posts  
- 📱 Fully responsive design for all screen sizes  
- 🎨 Clean and simple UI for smooth reading experience  



## Bonus Features (Advanced Ideas)

- 📝 Markdown editor with live preview while writing posts  
- 🖼️ Upload header images for blog posts  
- 🏷️ Add tags or categories to posts  
- 🔍 Filter posts by tags/categories in the feed  
- 🎬 UI animations and transitions for better UX  


##  Project Purpose

This project was built to practice real world web application development using React + Vite. It focuses on authentication, CRUD operations and managing user interactions in a structured way. It also demonstrates how blogging platforms handle content creation, display and user activity tracking.


## 🛠️ Tech Stack

- ⚛️ React (App.jsx)  
- ⚡ Vite  
- 📜 JavaScript (ES6+)  
- 🎨 CSS
